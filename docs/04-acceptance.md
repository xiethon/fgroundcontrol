# 第一阶段验收标准

## 功能与异常矩阵

| 对应需求 | 验收内容 |
| --- | --- |
| R01–R02 | 无账号、无互联网可连接；遥测与目标飞控及协议核对，单位与有效性明确；无线中断、重启、重连后状态正确 |
| R03 | 天地图及选定海外源可配置切换；位置、航线与轨迹对齐，切源不改变任务坐标；离线底图可用，缺少密钥或网络时反馈明确 |
| R04–R05 | 三种规划方式分别完成创建、编辑、保存、重开、预览；空输入、退化/自交几何、参数越界有明确处理 |
| R06 | 上传内容与快照一致；成功、拒绝、超时、重复请求和中途断线有确定结果；失败不误报成功 |
| R07 | 开始/暂停/继续/停止/返航逐项核对飞控行为；拒绝、超时、遥测过期、重复点击、断线与会话变化不会错误推进状态 |
| R08 | 执行中杀进程、重启、断线均保留可解释记录；匹配后才允许恢复；任务不一致或飞控已完成有明确处理；无自动续飞 |
| R09 | 完成、停止、中断均形成相应执行结果；时间、轨迹、面积及进度按已确认口径核对；缺失数据明确标记 |
| R10 | 三类日志按支持范围生成，可轮转、导出及关联任务；验证写盘失败、容量限制与异常退出；明确无法采集的崩溃类型 |
| R11 | 配置重启保持，目标屏幕布局可用，权限拒绝与恢复有明确反馈 |

## 验收分工

按 `rules/validation.md` 执行；UI 由用户验收。

## 综合门槛

- Android 构建通过，构建入口在新项目确定后写入 README。
- 首期建议实机连续运行至少 1 小时，无崩溃、明显卡顿或持续内存增长；最终性能阈值在 M0/M1 确定。
- 形成三种航线的端到端记录：规划 → 上传 → 执行 → 完成/中断 → 报告。
- 协议与执行先用模拟/SITL、再台架、再受控实飞验证。无硬件时记录未验收项，不能宣称完成实飞验收。
- 每项证据记录设备、系统、飞控版本、应用提交、输入、预期、实际结果与日志位置。

高风险逻辑优先自动化验证，UI 演示不能替代行为验收。

## 已确认行为的补充验收

- UDP：连接配置、丢包、断链和重连按最终链路契约验证，不因 UDP 无连接特性直接判定在线。
- 结束动作：分别上传悬停/返航任务；飞控实际进入末尾动作后作业计时停止，重复反馈不重复结束；返航未落地不显示为已落地。首期任务不含喷洒控制指令。
- 恢复失败：任务不匹配、身份不符或证据不足时进入人工处理，不发送自动续飞、重传或覆盖任务命令；仅简单弹窗说明原因，关闭不发送飞行命令。

- 继续时未解锁：明确拒绝且不发自动解锁命令。暂停/停止等待实际 Hold；停止结果为中断并保留恢复记录；拒绝、超时、断线与重复反馈不产生虚假成功或重复结束。

- 报告：规划/估算执行覆盖面积分列，暂停与返航不计时，离线缺失不补零或全量计入；首期本地查看，无报告导出要求（日志导出仍保留）。面积算法未冻结前不得标记面积验收通过。
- 生命周期与一致性：页面退出不终止连接/执行；旧会话和过期后台结果不更新当前任务；规划/写盘不阻塞主线程；并发命令/写入顺序明确；日志队列有界、写盘失败有诊断。异常退出后只使用完整一致的执行快照，缺失证据保持未知。以上均待代码与故障场景验证。

- 开始未解锁明确拒绝，不自动解锁；手动返航按中断保存恢复记录，不误报正常完成，拒绝/超时不误报已返航。
- 无效障碍物必须报错；覆盖重复区域按并集去重，缺失执行区间不推算。具体数值算法冻结后补充断言。
- MAVSDK：验证目标 ARM ABI/Android 9、server 后台启停、订阅清理、旧回调隔离、任务项/索引往返一致性及 SDK 错误/超时映射；尚未执行。

## M1 当前交付的验收入口

M1实现/验证/剩余用户验收按16-m1-acceptance.md逐项记录。通知拒绝不阻止前台连接服务，但可能不在通知栏展示；自动化分别核对服务foreground状态及已授权时通知存在。崩溃支持范围为JVM异常尽力保存并委托系统处理器，不要求强杀/原生崩溃必有堆栈。

## M2 对齐后的验收方向

逐字段核对遥测数值/单位/有效性，分别验证未收到/无效/过期；断线、重连、切预设、SDK进程退出后旧数据不污染新会话。相对高度/海拔分别标注。地图卫星+标注、切源、坐标一致性、离线及密钥/网络失败场景须覆盖；健康页面和事件记录须覆盖产生/重复/解除，无声音。具体阈值/数据新鲜度、地图方案需冻结后补数值断言。本轮仅确认方向，未执行功能验收。

M2已冻结阈值/协议见05、08；实施证据及待验收项目见17-m2-validation.md，取代上文“需冻结”状态。3秒整仍有效、超过3秒过期；20%不触发低电提醒、10%仍为提醒、低于10%严重。事件字段与周期字段区分，不以UI刷新时间延长新鲜度。
