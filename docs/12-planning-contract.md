## 已提取事实

- 地块：`src/core/mission/field/field_mission_planner_service.cc` 将边界、障碍物、边界内缩、障碍安全距离、航线间距、起点、参考边、入射角和优化开关交给规划器；多个边界逐一规划，任一失败返回错误。无输出明确失败。
- 自由航线：`src/core/mission/free_route/free_route_mission_planner_service.cc` 使用给定路线，按安全距离膨胀障碍物，航段相交或端点落入障碍物即拒绝；并非自动绕障。参考实现跳过部分无效障碍几何，这一行为尚未批准继承。
- AB：`src/core/mission/planner/ab/types.hpp` 输入 A/B、两端朝向和反向标记，参数含行距、行数、高度、速度。`ab/planner.cc` 含最短基线 0.5m、最少 4 行等限制；这些是参考常量，不是本项目已确认参数。
- 参考模型包含喷洒开关、禁喷区与喷量。本项目不控制喷洒，不能照搬相应任务指令；是否保留纯几何的区域分类尚未确认。

## 验收样例草案（预期待确认）

| 类型 | 输入场景 | 待确认预期 |
| --- | --- | --- |
| 地块正常 | 矩形边界、正行距、零内缩、无障碍 | 生成边界内往复覆盖路线，间距与方向可核对 |
| 地块边界 | 空边界、共线、自交；内缩后为空 | 明确拒绝，无可上传结果 |
| 地块失败 | 障碍物阻断可用空间 | 无可行路径明确失败，不生成穿障路线 |
| 自由正常 | 两个及以上有效不同航点 | 保持用户指定顺序 |
| 自由失败 | 航段穿过膨胀障碍物或端点位于其中 | 明确拒绝，不自动绕障 |
| AB 正常 | 有效不同 A/B、两端朝向、正行距与有效行数 | 生成往复路线；反向选择改变作业侧的精确规则需继续提取 |
| AB 边界 | A=B、非有限参数、退化区域 | 明确拒绝；阈值及参数范围待确认 |

## 已确认异常与面积原则

无效边界、无效障碍物、不可行路线统一明确拒绝；不继承参考实现跳过无效障碍的逻辑。面积按覆盖区域并集去重，估算执行覆盖只使用有执行证据的部分，缺失区间不推算。具体坐标、覆盖宽度与数值输出仍待固化，不将原则确认视为样例验收通过。
