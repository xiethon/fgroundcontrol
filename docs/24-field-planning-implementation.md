# 大田地块规划本地闭环实施计划

2026-11-19用户授权长步骤自主推进，普通未决取舍采用建议并记录；此前仅边界点范围在本轮扩展为地块规划本地闭环。无上传、解锁、起飞、执行或喷洒控制授权，不自动提交/合并/推送，不启动UI。

## 目标与顺序

1. 保留当前清理改动，核对参考固定提交、算法核心、第三方依赖与许可。优先剥离Qt适配复用纯几何核心；若需庞大Qt运行依赖则不直接引入。复用与重写的决定以可编译依赖、行为对照和维护成本为依据，不先承诺JNI或Kotlin方案。
2. 固化纯领域规划输入/结果、单位和版本。WGS84持久化，局部米制计算，相对Home高度；保留已确认参数范围及半行距首条规则。未指定起点/方向时采用确定性规则并记录，不能随运行随机变化。
3. 边界校验：点数、有限坐标、相邻重复/零长边、自交、退化、内缩后为空；明确失败，不静默删点或修复无效几何。不把无效输入变成可用航线。
4. 接入地块弓字往复覆盖，优先无障碍单地块，再评估多边形障碍与内缩。连接段必须在安全区内，不可行明确失败；不拿穿障直线或遗漏分区当作完成。矩形/凹多边形及障碍样例应能独立核对。
5. 规划移出主线程；编辑使旧结果失效。任务输入revision、算法版本和结果绑定，取消/旧任务结果不能覆盖新输入。限制点数和输出规模、防止病态几何导致阻塞，阈值应通过测试验证。
6. 持久化升级：旧边界草稿兼容读入；规划参数/输入/结果一致保存，异常/失败保留旧有效版本；新建清空规则沿用用户确认。结果与执行事实分开，不制造上传/完成状态。
7. 按Figma对应节点接入必要规划参数、生成/重算、路线预览及明确错误；复用token、地图和草稿，不加入无关设置。地图源切换不改变任务坐标。
8. 验证：矩形已知行数/长度、凹多边形、反向边界、近重复、自交/退化、参数端点/越界、无可行路径、大坐标/跨经度边界处理、写盘故障、重启与旧结果隔离。运行Android构建、单测、Lint，最后全阶段Review。

## 完成标准

正常地块可生成并保存/重开可解释航线；边界/安全区不合法或不可行时无可用结果；地图预览与保存结果一致；输入变化不显示旧有效结果；后台计算和失败路径验证有证据。UI最终由用户验收，不用构建成功代替。

## 本轮不做

AB/自由航线完整规划、圆形障碍、喷洒控制、飞控任务转换与上传执行、恢复报告、实飞。若几何核心复用缺条件，先报告已完成部分和准确阻塞，不以简化占位算法冒充参考复用完成。

## 当前实际状态
