# 决策与待确认事项

## 已确认（2026-11-16）

- Kotlin + Compose Android，最低 Android 9（API 28）；7 寸标准，兼容 5 寸及手机横屏，中英文。
- 单 UAV、大田地块/自由航线/AB；不做并行任务、队列或组合任务；首期无视频、账号和业务服务器，允许地图联网。
- PX4 v1.17.0 固定基线，标准 MAVLink，无自定义 XML、消息或私有命令。升级重新核对。
- 无线 UDP；设备型号/分辨率、端口/地址/发现方式可延后，实施前仍须明确。
- 中国天地图，海外覆盖欧美；具体海外源及离线方案可延后，实施前明确。
- 首期不控制喷洒，上传不含喷洒指令；App、飞行、崩溃三类日志，不下载 ULog。
- 暂停/停止等待飞控实际 Hold；停止记中断、保留恢复记录。继续要求已解锁，不自动解锁，等待实际 Mission 后恢复计时。拒绝、超时、断线不能记成功。
- 正常末尾可选悬停或返航，随任务上传固定；实际进入末尾动作即结束作业计时，返航/落地状态独立记录。
- 恢复核对失败仅简单弹窗说明，关闭不发命令；不自动续飞、重传或覆盖任务。
- 报告分列规划覆盖面积与估算执行覆盖面积，非实测喷洒面积；暂停/返航不计时，未知离线时间标记缺失，首期仅本地查看。
- 规划、执行、恢复参考 `/Users/xiethon/fairland/fgroundcontrol`，提交 `2383502523581d0755ebabb948b71df21aae845a`。私有喷洒、乐观状态更新及组合任务不继承。用户授权提取规则再确认，尚未批准所有参考常量。

## 最新业务确认与 MAVSDK 选型

- 开始与继续均要求用户先单独解锁，App 不自动解锁。
- 手动返航结束作业计时，记为中断并保留恢复记录；继续展示飞机返航/落地状态，不误记正常完成。
- 无效边界、无效障碍物及不可行路线统一明确拒绝，不静默忽略异常几何。
- 覆盖面积采用区域并集去重，区分规划覆盖与有执行证据的估算覆盖；缺失区间不推算。具体覆盖宽度、几何算法与数值样例仍需固化。
- 用户指定 MAVSDK 作为标准 MAVLink 接入库，不自行实现一套上传/命令协议栈；SDK 返回结果仍不替代实际飞控状态。
