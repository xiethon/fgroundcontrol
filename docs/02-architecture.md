# 架构设计

建议架构，选型与状态机待评审。

## 分层与依赖

Compose UI → 页面状态/ViewModel → 业务用例与领域模型 → 服务接口；通信、数据库、日志及平台模块实现服务接口。业务核心不依赖 Compose、Android 页面或具体数据库。使用协程管理异步工作，StateFlow 发布页面状态，核心操作明确串行化边界。

建议逻辑模块：UI、UAV/会话、任务领域、规划、上传与执行、健康、报告、存储、日志、MAVLink/链路、Android 平台适配。初期可按包组织，不必为每个逻辑模块立即建立 Gradle 模块。

## 多任务类型扩展

公共框架负责任务身份、版本、生命周期、持久化、上传协调和执行记录；任务类型实现自身参数模型、编辑、校验、规划与报告扩展。首个实现为大田任务，包含地块/自由航线/AB 三种规划输入。禁止公共层通过大量任务类型分支实现扩展。

规划输入 → 统一规划结果 → 飞控任务转换 → 不可变上传快照 → 执行记录 → 报告。坐标系、高度基准和单位必须显式定义。首期不生成喷洒控制指令，相关几何分类是否保留待确认。

## 数据与状态

核心数据：任务定义、版本、规划结果、上传快照、执行记录、事件、报告。任务可多次执行；编辑产生新版本，不能修改正在执行的快照。报告引用执行事实与计算规则版本，未知数据不按零值填充。

分别维护连接会话、上传状态、命令事务、飞控执行状态及本地记录状态。命令发送、ACK 接受和实际状态达成是不同事件。明确目标 system/component、超时、重复操作和重试约束；危险命令不得盲目重试。

重连后读取飞控任务与执行状态，与本地快照及执行记录匹配；无法可靠匹配时仅简单弹窗提示，关闭不发送飞行命令。进度索引明确飞控序号与业务航点映射。停止与返航分别建模，完成、失败、中断不能混为同一状态。

## 日志体系

- App 日志：启动、页面关键操作、服务、通信摘要和异常。
- 飞行日志：遥测、飞行事件、用户命令、ACK、任务上传及执行变化。首期不下载 ULog。
- 崩溃日志：未捕获异常、可获取的原生崩溃线索、版本与设备上下文；进程被系统终止不保证可生成崩溃栈。

日志关联 sessionId、UAV 标识、taskId、revisionId、executionId，并记录墙钟与单调时间。后台有界队列写入，定义溢出策略、轮转、容量和保留期限；关键执行事件与任务数据保持可恢复一致性。日志写入失败不得阻塞飞行链路，需要可见诊断。导出提供关联清单并控制敏感数据。崩溃现场不执行复杂业务或依赖异步写盘成功。

## 平台与复用

Android 首期使用 Kotlin + Compose。跨平台需求确认后再决定是否引入 KMP。UDP 链路、权限、前后台生命周期和原生崩溃采集由平台层负责。现有 C++ 规划算法按许可证、性能及可维护性评估复用；不默认逐行翻译。暂不引入视频或账号服务。

## 地图

- 地图渲染与地图源分离；统一配置图层、坐标转换、密钥及离线能力。
- 中国使用天地图，其他地区支持可选的主流地图源，具体供应商待选型。
- 切换地图源不改变任务原始坐标；显示转换与飞控坐标分离。
- 核对供应商授权、署名、离线许可与密钥管理；地图服务联网不包含账号或业务服务器功能。

## 通信协议

标准 MAVLink 交互参考 QGroundControl 与 PX4，以固定 PX4 v1.17.0 及标准 MAVLink为准；依据与版本记录在 `08-protocol-index.md`。

### MAVSDK 接入方案

通信适配层采用 MAVSDK；Android 优先评估 MAVSDK-Java 与本地 mavsdk_server，经服务接口隔离，领域层不依赖 SDK 类型。版本、原生 ABI 和 Android 9 兼容性在依赖冻结前核对，不因选型宣称已兼容。

官方 Java 仓库包含 Android server 库，要求 server 启停进入后台事件队列，避免发现系统时阻塞 UI；当前说明不支持 Android x86/x86_64。设备 ABI 未明确前保留为工程验证条件。server/订阅生命周期跟随连接服务，释放旧会话订阅并拒绝过期回调，不随页面销毁。

Mission 与 MissionRaw 能力须对照完整上传快照、末尾悬停/返航、索引和只读恢复核对要求后选定；不默认高层 Mission 支持全部任务项，也不因底层支持就假设 Java 绑定可用。SDK 内部重试和错误结果应纳入事务契约，业务层不叠加盲目重试。

来源：https://github.com/mavlink/MAVSDK-Java 、https://mavsdk.mavlink.io/main/en/cpp/guide/general_usage.html 。仅文档核对，尚未接入或构建。

### M1 落地补充

MAVSDK Java/server4.1.0运行于:mavsdk非导出专用进程，主进程经Messenger串行管理，旧消息带token过滤。主前台服务承载连接生命周期，切换/停止回收子进程，不并发销毁仍阻塞的native实例；具体实现及复验见14/15。日志正式策略、回放输入边界和任务状态以05/07/16为准。
