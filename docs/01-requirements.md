# 第一阶段需求

## 目标与边界

Kotlin + Compose Android 离线作业系统：连接 → 规划 → 上传 → 执行 → 恢复 → 报告。

支持任务类型扩展，首期仅大田任务，不做并行执行或任务队列。

首期按单 UAV 规划。飞控使用 PX4 稳定版本及标准 MAVLink，不引入自定义协议。规划、执行与恢复参考项目及冲突处理见 05-decisions.md。

## 功能需求

| R03 | 地图源可选：中国使用天地图，其他地区适配主流地图源；支持离线地图、机体位置/朝向、轨迹、缩放平移与跟随；海外欧美采用MapTiler，离线为授权栅格PMTiles |

| R05 | 保存任务定义、规划输入、航线结果及参数；区分草稿、待执行、执行中、未完成、已完成等状态，最终状态机需评审 |
| R06 | 上传前校验，显示进度、成功与失败；明确 ACK、超时、重试、取消和重复上传规则 |

| R08 | 本地持久化执行进度和中断原因；重启/重连后核对飞控任务与状态，提供恢复处理，禁止自动续飞 |

## 非功能要求

通信、解析、规划与写盘不阻塞 UI；遥测展示按需降频而非丢失核心状态。连接会话隔离，旧会话消息不能污染当前状态。任务、记录与报告离线持久化，异常退出后可恢复到可解释状态。遥测过期或链路不安全时禁止依赖这些数据发出新的危险操作。

权限、前后台运行策略、容量上限及性能阈值需在目标硬件确认后补充。

平台：7 寸屏为标准，兼容 5 寸屏与手机横屏；已确认最低 Android 9（API 28），设备待确认项见 05-decisions.md。海外地图首期覆盖欧美。首期飞行日志仅 App 侧记录，不包含 ULog 下载。

已确认平台与范围：最低 Android 9（API 28），飞控协议基线固定 PX4 v1.17.0；首条连接链路使用无线，采用 UDP，端口/地址/发现配置待明确。首期不控制喷洒，规划和上传不包含喷洒控制指令；报告不将规划覆盖面积表述为实测喷洒面积。

无线传输采用 UDP。正常任务末尾可选悬停或返航，进入末尾动作即结束作业计时；返航/落地状态独立展示。恢复核对失败由人工处理，禁止自动续飞或自动覆盖飞控任务。

报告口径已确认：规划覆盖面积与估算执行覆盖面积分列，暂停和返航不计作业时间，未知离线时间标记缺失，首期仅本地查看。恢复核对失败仅简单弹窗提示，关闭不触发飞行命令。

执行约束：继续要求已解锁，不自动解锁；暂停/停止等待实际 Hold；停止记中断并保留恢复记录。完整失败转换仍按状态机待固化项推进。

## 最新业务确认与 MAVSDK 选型

- 开始与继续均要求用户先单独解锁，App 不自动解锁。
- 手动返航结束作业计时，记为中断并保留恢复记录；继续展示飞机返航/落地状态，不误记正常完成。
- 无效边界、无效障碍物及不可行路线统一明确拒绝，不静默忽略异常几何。
- 覆盖面积采用区域并集去重，区分规划覆盖与有执行证据的估算覆盖；缺失区间不推算。具体覆盖宽度、几何算法与数值样例仍需固化。
- 用户指定 MAVSDK 作为标准 MAVLink 接入库，不自行实现一套上传/命令协议栈；SDK 返回结果仍不替代实际飞控状态。

手动返航以实际进入返航状态为停表及中断依据，拒绝不结束原作业，超时待核对；估算面积使用独立覆盖宽度，未配置显示未知，不以行距代替。

连接交互：使用参考项目的设备预设，无需手动输入端口，保存上次连接预设；默认 Local UDP 14551。固定远端地址不被入站来源覆盖，启动恢复选择并自动连接。

自动连接新要求：进程启动使用已保存预设自动连接，切换预设自动替换旧连接，页面不提供连接/断开按钮。支持 PX4 SITL UDP 接入，界面标明仿真；不因自动连接发送飞行操作。

## M2 已确认范围

- 自动连接及只读遥测、地图显示和健康提示；无任何解锁、上传或飞行控制入口。
- 长度/高度m、速度m/s；相对起飞点和海拔高度分别标注，缺失/无效/过期不显示为0。
- 地图卫星影像+道路标注，中国天地图、海外欧美；采用MapTiler及授权栅格PMTiles；不默认批量下载。切源不改变原始坐标。
- 健康提示覆盖链路、遥测新鲜度、GPS/定位、电池、飞控健康和状态文本；只做页面与日志，不做声音告警。
- 当前SITL开发验证与固定PX4 v1.17.0验证分开，不能互相替代。遥测/健康具体契约和验证见08、17及18。

M2地图采用MapLibre渲染，天地图/MapTiler密钥通过页面填写或本地配置构建注入，不把真实值提交源码；离线为授权PMTiles v3栅格包导入（含所需标注），不默认下载供应商瓦片。关键周期遥测超过3秒标过期；低于20%/10%分别提醒/严重，过期数据不宣称恢复正常；只读提示不触发飞行行为。
