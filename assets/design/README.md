# 设计资源参考档案

本目录保存界面资源原稿、来源、固定版本及哈希清单，供设计核对和资源转换使用，不参与Android运行时加载。

- `startup`：首页及启动流程原稿。
- `methods`：作业方式选择页资源。
- `topbar`：参考项目顶部栏原稿。
- `flight-topbar`：Figma飞行顶部栏原稿及清单。
- `flight-dashboard`：仪表盘原稿、动态实现依据及清单。
- `fonts`：字体来源、版本和校验清单。

运行资源位于`app/src/main/res`，随包许可证位于`app/src/main/assets/licenses`（路径相对仓库根目录）。不要在此放置密钥、临时下载地址、构建产物或运行日志。新增资源应在对应功能目录记录来源和用途，参考原稿不等于正在使用的运行资源。

清理约定：运行资源删除前核对代码/XML与动态引用，并执行Android构建和Lint；保留可复用原稿及来源记录，不将历史进度当成当前资源清单。旧资源与新设计资源并存的原稿用于追溯，不重复打包。
