# 飞行仪表盘资源与动态实现

设计：Figma fgroundcontrol，10 Screens→状态栏→FlightInstrumentPanel（4511:30723），主布局参考1280×800，仪表盘区域宽656、底部数据条604，仪表80，三个辅助按钮40/图标24，间距8/4。全部布局/字体/颜色集中于AppTokens的DashboardTokens/AppColors/AppType。

Figma中的两个仪表为不可分层的静态位图，不用于假装实时读数。用户确认采用参考项目动态实现，因此姿态/罗盘图层从参考提交2383502523581d0755ebabb948b71df21aae845a的assets/icons/components/attitude_indicator与compass_indicator复制，SVG原件保留，经librsvg按原尺寸转换为PNG。SVG自带不同viewBox：姿态盘/指针288×288、十字线288×36，罗盘160×160/箭头72×72；Compose用Fit保留长宽比，主体80、十字线比例.75、箭头比例.4，参照TelemetryPanel.qml及对应仪表组件。

另3个辅助图标来自设计上下文独立SVG（定高/避障/绕障），下载到本目录后同样转换为PNG，不提取路径重绘；无临时下载地址。资源大小/哈希见assets.json。

动态语义：地平线和滚转刻度反向随roll旋转，俯仰按参考height/45下移；罗盘箭头按归一化yaw顺时针旋转。俯仰刻度基于参考PitchIndicator的.55仪表比例/.15间距/5度步进绘制。缺失/失效不显示运动图层，以破折号替代；不使用参考项目缺失值补零。

视觉反馈修正：天空/地面改用设计原素材#0A84FF/#00E676；中央机翼来自5430:26822的独立SVG（wing 26×2、center 38×11.928），按160基准缩放，不重绘路径。figma_attitude_ring.svg是复合完整仪表，仅供设计核对，不用于覆盖动态画面；原参考cross_hair保留为来源记录，已不参与运行呈现。

最新排版以用户提供的整页参考图为准：罗盘→2×2数据→姿态仪→竖排辅助按钮，标签在数值上方，统一底板；原4511:30723仅保留为资源/字体/配色依据，不再作为上下分层布局约束。

实际运行复核后采用616面板/148仪表/116指标宽与胶囊裁切。姿态仪外圈按设计整圈刻度动态绘制，原参考dial/pointer仅保留来源核对，不再叠加到运行画面；刻度步进/长度集中于DashboardTokens。

按钮边界：最右侧3个辅助按钮独立于仪表盘底板，二者是外层Row的兄弟节点，间距复用AppSpace.xs；胶囊底板仅含罗盘、指标和姿态仪。
