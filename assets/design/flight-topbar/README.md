# 飞行顶部栏设计资源

来源：Figma fgroundcontrol，10 Screens → 状态栏 → FlyingScreen → TopStatusBar，节点254:7522；功能参考仓库2383502523581d0755ebabb948b71df21aae845a的TopStatusBar.qml/TopStatusPrimaryPanel.qml。设计原件不修改。

assets.json记录1张独立背景和7个图标的本地PNG/哈希；SVG原件在本目录，按原始尺寸经librsvg转换，不重绘路径。背景为设计提供的独立纹理，不是整栏截图。无临时下载URL。主体作业方式40、下拉角标12、GNSS32、电池32×39（包含投影边界）、百分号12×20、地图/设置40；手动图标复用既有Figma资源的48×46含投影尺寸，主体槽位40。

实际几何以节点元数据为准：1280×72，64高分组位于y=4，横边距8、组间距12、底圆角16，主状态48高。生成代码中的上下8边距与节点实际y=4不一致，使用实际元数据4。全部尺寸/颜色/字体集中在AppTokens.kt，统一屏幕比例；系统字体放大时增高栏与状态区，避免固定行框纵向截断。

当前只读范围仅GNSS与单飞行器电池，不搬双电池、温度、遥控器、喷洒示例；温度位置显示实际电压。主状态保留实际连接/模式/解锁信息，不用Standby示例覆盖真实状态。Noto Sans SC用于状态文字，Anton 400用于有效数值；缺失/失效显示原质量说明，不用数字0代替。
