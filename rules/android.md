# Android 规则

- 分离 UI、业务、数据和平台层；领域模型不依赖 Android/Compose。
- ViewModel 提供只读 StateFlow；UI 不直接操作 MAVLink 或数据库。
- 使用不可变状态、构造函数注入和结构化协程；不使用 GlobalScope，不吞取消异常。
- I/O、规划和写盘移出主线程；连接与执行不随页面销毁，资源及时释放。
- 生命周期感知地收集 Flow；副作用使用 Effect，正确设置键和清理逻辑。
- 高频遥测按需降频，列表使用稳定键；任务状态持久化，不依赖 rememberSaveable。
- 使用统一主题和资源字符串；适配遥控器屏幕，明确失败、断线和数据过期状态。
- 命令管理目标、ACK、超时、拒绝及实际状态；防止重复提交和盲目重试。
- 隔离连接会话；断线或数据失效时限制危险操作，恢复前核对状态，不自动续飞。
- 分离任务定义、版本、上传快照、执行记录和报告；执行快照不可修改，支持任务类型扩展。
- 离线可用，数据库支持迁移；三类日志关联会话和任务，后台有界写入、轮转和导出。
- MAVLink 交互参考 QGroundControl 与 PX4；先核对固定飞控版本与标准 MAVLink，依据见 `docs/08-protocol-index.md`。
